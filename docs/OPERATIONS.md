# 批次操作

1. 用带异常样例做阶段预览，查看列数、必填值和冲突记录。
2. 执行批次后，在业务阶段定位异常分组并核对原始记录键。
3. 在回收演练面板查看将释放容量、留存对象及依据（活动快照、合法保全、保留期、未对平）和按源行号列出的隔离行。留存对象不会被删除。
4. 先看“执行前对账”：源行、保留行、可回收行和隔离行任一项不一致，执行被挡住，先修来源再重跑。
5. 对账一致时按窗口决定：
   - `先释放`：只释放已确认安全的对象，其余留待后续演练，记录 `PARTIAL`。
   - `等齐后整批`：暂不释放，记录 `HELD`。
   - `整批签发`：所有分组通过且无隔离行时才可用，记录 `APPROVED`。
6. 导出复核证据并保存于交接记录。同一来源内容重跑沿用原批次，不会新增演练或改写已签发结论。

单文件 256 KiB，最多 2000 条逻辑记录。容器重启后保留批次。恢复时使用原 Docker Compose 数据卷。
